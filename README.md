# GoDigiWeb Next.js website

Run locally with `npm install` and `npm run dev`.

Import this repository into Vercel and use the default Next.js build settings.

Light website design with the GoDigiWeb gold and white identity. Gold accent: #F7BD2D; dark text: #182238.

Before production: replace the text logo lockup with the official logo asset, replace the founder monogram with an approved portrait, verify all client results and metrics, connect the booking CTA to the real calendar and GoHighLevel, migrate blog posts and add 301 redirects, and configure analytics, sitemap, robots.txt, and legal pages.
